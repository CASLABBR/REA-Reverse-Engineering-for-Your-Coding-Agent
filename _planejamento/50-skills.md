# 50 skills para uma pessoa nova na era da IA

> Curadoria feita em 2026-10-28. Critério: cada skill precisa **resolver um trabalho que se repete**, ter **saída em formato fixo** e **funcionar sem o usuário saber prompt engineering**.

## Como escolhi

1. **Repetição real** — se acontece menos de 1x/mês, não entra.
2. **Saída verificável** — arquivo, checklist, número, decisão. Não "dicas".
3. **Baixo risco** — nada de diagnóstico médico, jurídico ou financeiro como conselho final; a skill organiza e pergunta, não decide por você.
4. **Alavancagem** — usa o que o Bionic já faz bem (documentos, código, pesquisa, arquivos locais).
5. **Curva de aprendizado embutida** — ensina o método enquanto entrega o resultado.

O que **não** vale virar skill: "escrever código", "resumir textos", "ser um assistente melhor". São amplos demais e o modelo já faz — skill só ganha quando fixa **processo + formato + critério de qualidade**.

## Padrão de construção (vale para todas)

Toda skill da central segue o mesmo esqueleto:

```
E:\INTELIGENCIA_ARTIFICIAL\SKILL\<nome>\
├── SKILL.md            # quando usar + processo + formato de saída
├── assets\             # templates, checklists, exemplos
└── referencias\        # (opcional) guias longos, lidos só quando preciso
```

Regras:

1. **Descrição** curta, dizendo *quando* usar — é o que o modelo lê sempre.
2. **Processo numerado**, com pontos de decisão explícitos.
3. **Formato de saída obrigatório** (seções fixas). É isso que garante consistência.
4. **Critério de aceite** ("só entregue quando…") — evita entrega meia-boca.
5. **Checklist de autoverificação** no final do `SKILL.md`.
6. **Teste real**: 3 casos diferentes antes de considerar pronta. Falhou em 1 → ajusta a regra.

## Ordem sugerida de produção

- **Semana 1:** fase 1 (10 skills) — é o que dá sensação imediata de "isso mudou meu dia".
- **Semana 2:** fase 2 (7) — comunicação é onde a IA mais economiza tempo.
- **Semana 3:** fase 3 (6) + fase 4 (7) — pesquisa e documentos profissionais.
- **Semana 4:** fases 5 a 8 — conforme a sua rotina pedir.

A cada skill pronta: instalar globalmente, testar em 3 tarefas reais e deixar o `learning-map` registrar o que funcionou.
