# Git Flow Helper

Fonte: `E:\INTELIGENCIA_ARTIFICIAL\SKILL\git-flow-helper`. Pertence à central de skills; use junto com `learning-map`.

## Quando usar

- A mudança virou um commit gigante.
- Precisa explicar a mudança para revisão.

**Não use para:** commits automáticos de ferramenta.

## Processo

1. Quebre a mudança em commits atômicos por intenção.
2. Escreva mensagem imperativa com escopo e motivo.
3. Use branch descritiva.
4. Monte o PR com o que mudou, por quê e como testar.

## Formato de saída

- Sequência de commits
- Branch criada
- Descrição de PR pronta

## Critério de aceite

- cada commit compila sozinho
- mensagem explica o porquê, não só o quê

## Regras gerais

- Não invente dado, número ou citação. Faltou informação? Pergunte (máx. 3 perguntas) ou declare a suposição.
- Quando o formato permitir, entregue arquivo, não só texto no chat.
- Se o pedido fugir do escopo desta skill, diga isso e faça o trabalho normalmente.
- Ao terminar, registre o resultado no `LOG.md` do `learning-map`.
